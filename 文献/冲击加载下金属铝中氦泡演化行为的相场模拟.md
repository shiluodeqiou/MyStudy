# 冲击加载下金属铝中氦泡演化行为的相场模拟

万    曦，姚松林，裴晓阳

（中国工程物理研究院流体物理研究所冲击波物理与爆轰物理重点实验室, 四川 绵阳　621999）

摘要：氦泡等缺陷对金属材料动态强度的影响一直是动态强度研究关注的重点。将相场方法引入冲击加载下氦泡演化行为研究中，通过与晶体塑性理论耦合，建立了可描述冲击下氦泡早期演化行为的介观模拟技术。应用该方法，针对含氦泡的金属铝材料，从介观尺度对氦泡的演化行为及其对位错集体演化行为的影响进行了研究。结果表明：氦泡结构的非均匀性导致局域应力集中和塑性变形集中，局域塑性变形集中会导致沿冲击波传播方向发射稀疏波；从能量守恒角度上看，在材料变形过程中氦泡生长与塑性变形呈竞争关系，塑性耗散的快慢直接影响氦泡的生长速率，使其发生改变。研究结果可为解读含氦泡材料的宏观屈服强度和层裂行为提供理论支撑。

关键词：冲击加载；氦泡；相场模型；晶体塑性

材料在加工和储存过程中不可避免地会产生缺陷。缺陷的存在可能显著影响材料的力学性能，因此相关研究得到持续的关注。放射性环境下，材料可能遭受氦原子或氦离子等粒子的辐照，从而在材料中形成氦泡等缺陷<sup>[1–2]</sup>。已有研究表明，氦泡的存在会显著影响材料的力学性能<sup>[3–6]</sup>，包括动力学性能和静力学性能。早期的研究集中在准静态研究领域，主要关注氦泡导致的氦脆与肿胀现象<sup>[3–7]</sup>。近年来，强动载荷下氦泡的行为与影响得到越来越多的关注<sup>[8–22]</sup>。强动载荷下材料的变形是一个超快动力学过程，力学响应一般呈现显著的时间非平衡和空间非均匀等特性，相关研究十分复杂而困难。然而，受测量手段和实验条件的限制，无法实时得到冲击过程中材料内部的演化过程<sup>[23–25]</sup>。当前，人们主要通过测量强动载荷下材料的界面粒子速度获得高时间分辨的动态变形信息，再结合样品回收表征以及理论建模反推材料内部的变形过程<sup>[26–29]</sup>。

微介观尺度下，人们主要通过表征回收样品<sup>[14–15]</sup> 或者原子模拟<sup>[18–20]</sup> 获得氦泡的演化规律及其对局域塑性变形的影响特征。Glam 等<sup>[17]</sup> 通过表征回收样品，发现冲击加载前后氦泡出现明显的聚集长大特征，这对深入认识损伤演化早期底层变形机理具有十分重要的意义。Shao 等<sup>[18]</sup> 通过原子模拟对整个层裂过程中损伤形态的演化进行了研究，指出动态拉伸过程中大孔洞的形成源于小孔洞的汇合，而初始孔洞与氦泡的存在抑制了孔洞的长大。此外，Kubota 等<sup>[12]</sup> 通过在模型中预设不同类型的初始缺陷，研究了不同类型的初始微缺陷及不同尺寸的氦泡对材料动态强度的影响；王海燕等<sup>[8]</sup> 则对氦泡局域应力分布导致的位错演化非均匀性进行了研究。

宏观尺度下，人们通过测量速度波剖面，获取了含孔洞材料的状态方程、屈服强度以及拉伸强度，通过建立基于均匀化假设的唯象模型，对实验现象进行了解释。例如：Reisman等<sup>[10]</sup> 首先采用准等熵实验获得了孔隙度对辐照不锈钢力学响应的影响规律，随后通过建立含孔洞坍缩的演化方程，再现了因孔洞坍缩导致波剖面塑性前沿斜率显著降低的关键特征。Raicher 等<sup>[13]</sup> 建立了含氦泡铝的状态方程，并检验了氦泡的存在对材料冲击加载响应的影响。Glam 等<sup>[17]</sup> 采用冲击加载手段对反应堆辐照掺硼铝样品的层裂强度进行了系列研究，结果表明，不同环境温度下氦泡对层裂强度的贡献呈现相反的趋势，室温下氦泡的存在导致层裂强度增大，而高温下则导致层裂强度显著降低。他们采用一个含氦泡内压的唯象模型，再现了室温下氦泡导致层裂强度增大的实验现象，却没有明确指出导致该现象的原因。对于高温下氦泡导致层裂强度减小的实验现象，Glam 等则定性地指出，可能是由于氦泡的存在降低了塑性流动，同时有助于孔洞增长。

总的来说，当前对氦泡如何影响材料动力学行为的研究，无论是实验还是理论模拟都相对较少。如何利用有限的实验数据获取更丰富的动态变形信息，对数值模拟工作提出了更高的要求。宏观模拟完全忽略了微结构演化行为，对真实物理过程的描述不够合理，且完全忽略了氦泡与位错的相互作用。原子模拟可以有效地描述单个氦泡的演化行为及其对局域位错演化的影响，但所能描述的时空尺度有限，且原子模拟结果难以给出氦泡演化行为对位错集体演化行为的影响，进而限制了其为更大尺度力学响应特征提供理论支撑。

就动载下氦泡的演化行为而言，目前还缺少一个可以在更大时空尺度下考虑氦泡微结构效应，并可有效描述氦泡与位错演化相互影响的模拟技术。在前期的工作中，我们已证实相场（phase field）方法可以有效描述冲击下新相的生长过程，并能够与宏观力学响应有效关联起来。类比新相生长过程，氦泡的生长过程同样有望用相场方法描述，而晶体塑性理论可以在连续尺度描述塑性流动行为。为此，本研究将相场方法引入冲击加载下氦泡的动态演化行为分析，通过与晶体塑性理论耦合，对冲击加卸载过程中氦泡的演化行为及其对局域塑性变形的影响进行探讨，以获得规律性认识。相关研究可为解读宏观强度行为提供理论参考。

## 1 理论模型

在模拟材料的动态力学响应时，一般选用流体弹塑性模型描述<sup>[30]</sup>。基于流体弹塑性假设，可将变形拆分为球量响应和偏量响应，分别采用状态方程和本构模型予以描述。本研究将在流体弹塑性理论框架下处理含氦泡铝材料的力学响应。

分别建立不同的模型描述基体铝材料和氦泡的力学响应，采用相场模型描述氦泡的演化，采用晶体塑性模型描述基体铝材料的弹塑性响应。采用晶体塑性模型描述基体铝材料的弹塑性响应的原因在于，大量的研究已经证实晶体塑性模型可以较合理地描述冲击加载下材料的黏塑性响应，从而更加准确地预测氦泡/基体铝材料界面处的应力分布，进而更加合理地描述氦泡生长行为。而选择相场模型描述氦泡的演化行为则主要是由于相场方法具有强大的界面处理能力。下面将分别介绍相场模型和晶体塑性模型。

## 1.1 流体弹塑性分解

一般把材料的力学响应拆分为球量响应与偏量响应两部分，分别由状态方程和本构模型描述。应力张量 $\sigma$ 被拆分为静水 $\operatorname { \mathrm { { F } } } \sigma _ { \mathrm { { h } } }$ 和应力偏量 $\sigma ^ { \prime } , \sigma = - \sigma _ { \mathrm { h } } I + \sigma ^ { \prime }$ ，而应变张量 $\pmb { \varepsilon } ^ { \mathrm { e } }$ 被拆分为体应变 $\varepsilon _ { V } ^ { \mathrm { e } }$ 和应变偏量$\varepsilon ^ { \prime \mathrm { e } } , \varepsilon ^ { \mathrm { e } } = \varepsilon ^ { \prime \mathrm { e } } + I \varepsilon _ { \scriptscriptstyle V } ^ { \mathrm { e } } / 3 ^ { [ 3 1 ] }$ ，其中 $\pmb { I }$ 为二阶单位矩阵。在各向同性材料中，静水压体现了与体积变化相关的变形行为；而对于各向异性材料，材料的各向异性导致应变偏量也对静水压有贡献<sup>[32]</sup>。

静水压为3个主方向应力的平均值，可写作

$$
\sigma_ {\mathrm{h}} = \sigma_ {\mathrm{EOS}} + \frac {1}{3} \left(\boldsymbol {\varepsilon} ^ {\prime \mathrm{e}}: \boldsymbol {C}: \boldsymbol {I}\right) + \left[ \frac {1}{2} \left(\boldsymbol {\varepsilon} ^ {\prime \mathrm{e}}: \frac {\partial \boldsymbol {C}}{\partial p}: \boldsymbol {\varepsilon} ^ {\prime \mathrm{e}}\right) + \frac {1}{3} \left(\boldsymbol {\varepsilon} ^ {\prime \mathrm{e}}: \frac {\partial \boldsymbol {C}}{\partial p}: \boldsymbol {I} \varepsilon_ {V} ^ {\mathrm{e}}\right) \right] \frac {\partial p}{\partial \varepsilon_ {V} ^ {\mathrm{e}}} - \frac {1}{2} \left[ \boldsymbol {\varepsilon} ^ {\mathrm{e}}: \frac {\partial \boldsymbol {C}}{\partial T}: \boldsymbol {\varepsilon} ^ {\mathrm{e}} \right] T \Gamma - T \Gamma \Delta \eta\tag{1}
$$

式中： $\sigma _ { \mathrm { E O S } }$ 为静水压中只与体积变化相关的部分； $C = \left( \partial ^ { 2 } \pmb { \varepsilon } / \partial \pmb { \varepsilon } ^ { \mathrm { e } 2 } \right) _ { \pmb { \varepsilon } ^ { \mathrm { c } } = 0 }$ 为弹性常数张量； $p$ 为压力； $T$ 为温度；$\partial C / \partial p$ 和 $\partial C / \partial T$ 分别为弹性常数关于压力和温度的一阶偏导；含 $\partial { \pmb C } / \partial p  { \partial { \pmb C } } / \partial T$ 的几项表示变形过程中压力变化或温度变化引起弹性性质改变对应力的贡献； $T I \Delta \eta$ 表示变形过程中熵增对静水压的贡献，其Γ中 为 Grüneisen 系数。 $\sigma _ { \mathrm { E O S } }$ 可写作

$$
\sigma_ {\mathrm{EOS}} = \frac {1}{9} (\boldsymbol {I}: \boldsymbol {C}: \boldsymbol {I}) \varepsilon_ {V} ^ {\mathrm{e}} + \frac {1}{1 8} \left(\varepsilon_ {V} ^ {\mathrm{e}}\right) ^ {2} \left(\boldsymbol {I}: \frac {\partial \boldsymbol {C}}{\partial p}: \boldsymbol {I}\right) \frac {\partial p}{\partial \varepsilon_ {V} ^ {\mathrm{e}}}\tag{2}
$$

Becker<sup>[33]</sup> 与 $\mathrm { D e }$ 等<sup>[31]</sup> 分别用 Grüneisen 状态方程与 Birch-Murnaghan 状态方程代替式 (2)。考虑到Grüneisen 状态方程在冲击波物理中的普遍适用性，本研究采用 Grüneisen 状态方程描述 $\sigma _ { \mathrm { E O S } }$ ，该方程的具体形式为

$$
\sigma_ {\mathrm{EOS}} = \frac {\rho_ {0} C _ {0} ^ {2} \mu}{1 - (\lambda - 1) \mu} + \Gamma_ {0} E\tag{3}
$$

式中： $\rho _ { 0 }$ 为初始密度； $C _ { 0 }$ λ 和 为冲击 Hugoniot 线 $( D - u$ 曲线）的截距与斜率； $\mu = \frac { 1 } { \nu } - 1 , \nu$ 为比容； ${ \cal { T } } _ { 0 }$ 为标量形式的 Grüneisen 系数；E 为内能。

在描述塑性变形过程时，一般不采用全量形式的应力-应变关系，而采用增量形式，即

$$
\dot {\sigma} ^ {\prime} = l: C: (\dot {\varepsilon} - \dot {\gamma} ^ {\mathrm{p}})\tag{4}
$$

l ε˙式中： 为从二阶张量中提取偏量的算子， 为应变率， $\dot { \gamma } ^ { \mathrm { p } }$ 为塑性应变率。塑性应变率可由晶体塑性模型计算得到。

## 1.2 晶体塑性模型

晶体材料的塑性变形主要由位错滑移和孪晶变形引起，而位错作为塑性变形的基本单元在这两种机制中都起着重要作用<sup>[34]</sup>。采用 Orowan 方程可将宏观层面的塑性应变率与微观层面的位错运动以及位错生成关联起来，其表达式为

$$
\dot {\pmb {\gamma}} ^ {\mathrm{p}} = \rho_ {\mathrm{m}} \pmb {b} \pmb {v} _ {\mathrm{D}}\tag{5}
$$

ρ式中： 为可动位错密度， $\rho _ { \mathrm { m } }$ $ { \boldsymbol { \nu } } _ { \mathrm { D } }$ 为位错运动速度，b为伯格斯矢量。由 Orowan 方程可知，要在连续介质尺度准确地描述晶体材料的塑性变形，就必须明确位错速度和密度的演化规律。

位错在分切应力（即外加应力在滑移方向上的分量，分切应力 $\tau _ { \mathrm { s } } = \sigma _ { i j } m _ { i j } ^ { \mathrm { s } }$ ，其中 $\sigma _ { i j }$ 为外加载荷， $m _ { i j } ^ { \mathrm { s } }$ 为方向因子）的驱动下发生运动。经典位错运动理论根据外加应力水平以及位错运动速度大小将主导位错运动的机制分为 3 类：当分切应力小于临界分切应力时，热激活主导位错运动；当分切应力大于临界分切应力时，声子拖曳机制主导位错运动；当位错速度逼近横波声速时，相对论效应限制位错速度的无限制增大。

考虑到在本研究所处理的弱冲击加载问题中外加应力始终处于临界分切应力以上，因此不考虑热激活位错运动机制，而只考虑声子拖曳效应以及相对论效应对位错速度的控制。在一阶近似下，位错可以视为牛顿黏性流体，其动量变化率由牛顿第二定律表示<sup>[35–36]</sup>

$$
\frac {\mathrm{d}}{\mathrm{d} t} \frac {m _ {0} v _ {\mathrm{D}} ^ {\zeta}}{\left[ 1 - \left(v _ {\mathrm{D}} ^ {\zeta} / c _ {\mathrm{t}}\right) ^ {2} \right] ^ {3 / 2}} = (\tau_ {\mathrm{s}} \pm \tau_ {\mathrm{c}} b) - \frac {B}{\sqrt {1 - \left(v _ {\mathrm{D}} ^ {\zeta} / c _ {\mathrm{t}}\right) ^ {2}}} v _ {\mathrm{D}} ^ {\zeta}\tag{6}
$$

式中： $m _ { 0 }$ 为单位位错线的质量； $c _ { \mathrm { t } }$ ζ为横波声速； 表示不同的滑移方向，具有不同晶格结构的材料，其位错滑移取向也不同，具有面心立方（FCC）结构的金属的主要滑移系为 $\{ 1 1 1 \} { < } 1 1 0 { > }$ ，共 12 个滑移方向，具有体心立方（BCC）结构的金属的主要滑移系为{110}<111>，共 12 个滑移方向； $\tau _ { \mathrm { c } }$ 为临界分切应力，当分切应力小于临界分切应力时，位错保持静止；B 为黏性阻尼系数，本研究假设在高应变率下位错滑移所需克服的主要阻碍为声子黏性，因此B 与温度成正比，具体表达式参见 Kuksin 等<sup>[37]</sup> 的分子动力学计算结果。

采用 Austin 等<sup>[38–39]</sup> 提出的基于位错亚结构演化的本构模型描述位错密度演化，根据位错在塑性变形过程中的作用将位错区分为可动位错和不可动位错。可动位错负责塑性滑移，不可动位错负责控制材料的屈服应力，则有

$$
\tau_ {\mathrm{c}} = \tau_ {0} + A _ {\mathrm{I}} G _ {\mathrm{m}} b \sqrt {\rho_ {\mathrm{IM}}}\tag{7}
$$

式中： $\tau _ { 0 } .$ 为初始分切应力， $A _ { \mathrm { I } }$ 为硬化系数， $G _ { \mathrm { m } }$ 为剪切模量， $\rho _ { \mathrm { m } }$ 为不可动位错密度。随着不可动位错密度的增大，材料强度增大，位错启动滑移更加困难。

冲击波作用下，外加应力驱动位错以增殖和成核的形式生成，位错在运动过程中与阻碍相互作用，导致可动位错被俘获成为不可动位错，符号相反的位错相互作用时会发生湮灭。基于这一物理图像，位错亚结构演化方程可以表示为

$$
\dot {\rho} _ {\mathrm{M}} = \chi \dot {\rho} _ {\mathrm{HN}} + \dot {\rho} _ {\mathrm{mult}} - \dot {\rho} _ {\mathrm{trap}} - \dot {\rho} _ {\mathrm{anni}} ^ {\mathrm{M}}\tag{8}
$$

$$
\dot {\rho} _ {\mathrm{IM}} = (1 - \chi) \dot {\rho} _ {\mathrm{HN}} + \dot {\rho} _ {\mathrm{trap}} - \dot {\rho} _ {\mathrm{anni}} ^ {\mathrm{IM}}\tag{9}
$$

式中：下标 HN、mult、trap 和 anni 分别表示均匀成核、增殖、俘获和湮灭过程， $\chi$ 表示均匀成核生成的位错中运动一定距离后仍保持运动状态的位错占所有生成位错的百分比。位错成核、增殖、俘获与湮灭的控制方程见文献[38]。

## 1.3 基于相场方法的氦泡演化模型

相场模型是目前模拟材料微结构演化的重要的理论与计算工具。相场方法的优势在于可以反映界面演化的动力学效应。基于扩散界面的思想可以有效避免求解具有运动边界条件的微分方程组这一复杂的数学问题。相场模型借助序参量（场变量）将尖锐界面扩散为具有一定厚度的界面，界面的演化通过序参量的演化来实现<sup>[40–44]</sup>。

根据氦泡演化的物理图像，其生长聚集过程对应氦泡/基体界面扩散演化过程，相关问题有望用相场方法描述。本研究选择序参量描述氦泡/基体界面演化，序参量本身不具有明确的物理意义。选用序参量 $\eta$ 描述氦泡和基体铝材料的边界， $\eta = 0 \mathcal { \bar { H } } \mathbb { I } \eta = 1 \mathit { \Omega } _ { \mathcal { D } } ^ { \prime }$ 别对应基体铝材料和氦泡，通过描述 $\eta |$ 的演化实现对氦泡演化行为的描述。选用一定的插值函数，可得到变形过程中任意位置的比内能 $e$ 和比体积v

$$
e (p, T, \eta) = [ 1 - h (\eta) ] e _ {1} (p, T) + h (\eta) e _ {2} (p, T)\tag{10}
$$

$$
v (p, T, \eta) = [ 1 - h (\eta) ] v _ {1} (p, T) + h (\eta) v _ {2} (p, T)\tag{11}
$$

式中： $h ( \eta )$ 为插值函数，满足 $h ( 0 ) = 0 , h ( 1 ) = 1 , \frac { \mathrm { d } h ( \eta ) } { \mathrm { d } \eta } \bigg | _ { \eta = 0 , 1 } = 0 ,$ ，这里取 $h ( \eta ) = 3 \eta ^ { 2 } - 2 \eta ^ { 3 }$ ，这种插值形式使得每个纯相对应于系统的极值点，稳定性则由热力学稳定性条件判断。

应用相场方法求解界面演化问题的关键在于构建驱动界面演化的驱动力，即 Gibbs 自由能。Gibbs自由能 $G$ 包含系统的比内能、比熵、应变能。对于存在界面的系统，其自由能还包含与界面形成相关的序参量梯度项，即

$$
G = \int \rho \left(g _ {\text { local }} - \frac {\beta}{2} | \nabla \eta | ^ {2}\right) d V\tag{12}
$$

式中： $\eta$ 为非守恒序参量， $\beta$ 为梯度项系数， $g _ { \mathrm { l o c a l } } = e - T S + e _ { \mathrm { s t r a i n } } ( \sigma , \varepsilon _ { \mathrm { . } }$ )为局域 Gibbs 自由能， $e _ { \mathrm { s t r a i n } } ( \sigma , \varepsilon )$ 为应变能，S为熵。塑性变形对氦泡演化的影响通过应变能的形式反映到式 (12) 中 $^ { \circ }$ 在界面处对自由能进行插值，即可得到界面扩散的驱动力

$$
g (p, T, \eta) = [ 1 - h (\eta) ] g _ {1} (p, T) + h (\eta) g _ {2} (p, T) + T W f (\eta)\tag{13}
$$

W f(η)式中： 为势垒高度； 为双势阱函数，一般取 $f ( \eta ) = \eta ^ { 2 } ( 1 - \eta ) ^ { 2 }$ C

非守恒序参量演化由Allen-Cahn方程控制

$$
\frac {\partial \eta}{\partial t} = - L \rho \frac {\delta G}{\delta \eta} = - L \rho \left(\frac {\partial g}{\partial \eta} - \beta \nabla^ {2} \eta\right)\tag{14}
$$

式中： $L$ 为动力学系数，用于表征界面演化速率。由于冲击问题中需考虑材料的压缩性，因此式 (14) 中含有密度 $\rho _ { \varsigma }$ 。

在求得序参量之后，就可以进一步求解压力与温度的演化。这里将压力和温度随时间的变化率表示为比容和序参量随时间变化率的函数，即

$$
\left( \begin{array}{l} \dot {p} \\ \dot {T} \end{array} \right) = M \left( \begin{array}{l} \dot {\nu} \\ \dot {\eta} \end{array} \right)\tag{15}
$$

式中：M为系数矩阵，由系统的热力学状态确定。系数矩阵的具体形式见文献[40]。

在实际计算过程中，考虑到氦泡内压与物质密度均远低于外加载荷，因此忽略氦泡物质密度以及内压对计算结果的影响，即假设氦泡的密度和内压均为零。在处理氦泡覆盖的区域或氦泡/基体界面处相关力学参量时，物质密度、应力与内能均视为两种材料的加权平均，即

$$
\rho^ {\prime} = (1 - \eta) \rho\tag{16}
$$

$$
\sigma_ {i j} ^ {\prime} = (1 - \eta) \sigma_ {i j}\tag{17}
$$

$$
E ^ {\prime} = (1 - \eta) E\tag{18}
$$

## 3.1 氦泡的结构非均匀性

首先模拟分析了冲击压缩过程中单个氦泡与冲击波的相互作用。模拟结果表明，冲击波到达后，氦泡的结构非均匀性导致局域应力集中和塑性变形集中。从分切应力云图可以看出，分切应力最大值集中在4个对角线方向，对应剪应力最大方向，如图3所示。

从计算结果中提取了冲击压缩过程中位错密度的演化历史，如图 4 和图 5 所示。计算结果表明，可动位错密度主要集中在撞击面附近以及氦泡的 4 个对角线方向，最大位错密度约为 $1 0 ^ { 1 5 } \mathrm { m } ^ { - 2 }$ 。特别地，氦泡附近 4 个对角线方向对应剪应力最大值方向。随着应力波在样品中反复传播，氦泡对角线方向高位错密度区域逐渐扩展，同时氦泡周围的位错密度不断累积，在二维空间内逐渐将对角线方向高位错密度区域连接起来，如图5所示。

除变形局域化以外，计算结果表明，氦泡的存在还会导致应力波传播发生改变。冲击波与氦泡相互作用会导致沿冲击波传播方向发射稀疏波，沿垂直于冲击波传播方向发射压缩波，体现为氦泡附近纵向区域的压力低于铝基体区域，而横向区域的压力高于铝基体区域，如图3(a)和图3(b)所示。

氦泡与冲击波相互作用引起的应力波传播改变与于继东<sup>[40]</sup> 模拟的相变微结构与冲击波相互作用的结果一致。根据 Yao 等<sup>[45]</sup> 和 Gurrutxaga-Lerma 等<sup>[46]</sup> 最新的动态塑性变形研究结果可知，沿纵向发射的稀疏波实则为冲击波阵面上塑性松弛所发射的稀疏波。由于波后区域是超声速的，Gurrutxaga-Lerma 等在研究“弹性前驱衰减”现象时指出，该稀疏波会追赶上冲击波前，导致“弹性前驱衰减”现象出现。基于该认识，可以预期，氦泡与冲击波相互作用发射的稀疏波最终也会追赶上冲击波前，并导致弹性前驱进一步衰减。该研究结果能够解释 Glam 等<sup>[17]</sup> 在实验中发现的含氦泡掺硼铝的动态屈服应力略低于不含氦泡掺硼铝，即含氦泡材料的动态屈服应力略小于不含氦泡材料的动态屈服应力。

从能量的角度来讲，随着冲击波在样品中不断传播与反射，塑性耗散和氦泡演化共同导致能量耗散，卸载波初次到达氦泡所在区域时所携带的能量最大，为氦泡快速生长提供了条件，氦泡快速生长不断消耗卸载波所携带的能量，使卸载波携带能量急剧降低，进而导致氦泡演化驱动力减小，因此氦泡的生长速率在卸载波到达后达到极大值随后发生显著衰减

## 3.2.2 温度对氦泡演化行为的影响

采用同样的构型和模型参数，计算了 600 K 环境温度下氦泡的演化行为，并与室温下氦泡的演化行为进行了对比，如图 11 所示。计算结果表明，氦泡的生长速率随温度的升高而增大。该现象可以归因于声子拖曳机制主导冲击加载下的位错运动。在研究 FCC 金属的动态屈服应力热硬化现象时，Yao 等<sup>[45]</sup> 指出，声子拖曳机制作用下，位错运动速率随温度的升高而降低，塑性耗散速率更低。塑性耗

散速率的改变会导致氦泡演化的驱动力 Gibbs自由能发生改变

$$
g _ {\text { local }} = e - T S + e _ {\text { strain }} (\sigma , \varepsilon)\tag{19}
$$

其中，应变能 $e _ { \mathrm { s t r a i n } } ( \sigma , \varepsilon )$ 可以拆分为体应变能与剪切应变能之和

$$
e _ {\mathrm{strain}} (\sigma , \varepsilon) = e _ {\mathrm{vol}} (p, v) + e _ {\mathrm{shr}} (S, e)\tag{20}
$$

式中： $e _ { \mathrm { v o l } } ( p , \nu )$ 为体积应变能， $e _ { \mathrm { s h r } } ( S , e )$ 为剪切应变能。塑性耗散速率变慢会导致更多的剪切应变能$e _ { \mathrm { s h r } } ( S , e )$ 参与驱动氦泡长大，因此高温下氦泡的长大速率更快。根据这一物理图像可以预测，含氦泡铝材料的宏观层裂强度会随着温度的升高而降低，与 Glam 等<sup>[17]</sup> 的宏观实验观测结果一致，相较于不含氦泡的铝材料，随着温度的升高，含氦泡铝材料的层裂强度下降得更快。

## 4 总　结

基于相场方法建立了可描述冲击下氦泡演化的物理模型，并应用该模型研究了不同外加条件下氦泡的长大行为及其对局域位错集体演化行为的影响。结果表明：氦泡的结构非均匀性会导致局域应力集中和塑性变形集中；在与冲击波相互作用的过程中，局域塑性变形沿冲击波传播方向发射稀疏波，该稀疏波与塑性松弛过程发射的稀疏波共同导致动态屈服应力减小。从氦泡的生长行为来看，氦泡的生长与塑性变形呈竞争关系。在输入剪切应变能一定的情况下，更大的氦泡密度以及更快的生长速率会消耗更多的剪切应变能，导致塑性变形量更小，表观强度更大；反之，更快的塑性变形速率导致氦泡生长更慢，进而使层裂强度更大。尽管如此，由于氦泡本身是一种微观缺陷，因此暂时无法直接将其演化行为与宏观力学响应联系起来。另外，受限于有限元方法处理大变形的能力，目前暂时只能对早期的氦泡演化行为进行研究，无法模拟氦泡聚集并贯通这一物理过程。

# Phase Field Modeling of the Evolution of Helium Bubbles in Shock Loaded Aluminum

WAN Xi, YAO Songlin, PEI Xiaoyang 

（National Key Laboratory of Shock Wave and Detonation Physics, Institute of Fluid Physics, CAEP, Mianyang 621999, Sichuan, China） 

Abstract: Investigation of the influence of helium bubbles on the dynamic strength has drawn continuous attention.  In  this  article,  the  phase  field  method  (PFM)  is  applied  to  investigate  the  evolution  of helium bubbles  at  an  early  stage  in  shock-loaded  aluminum  based  on  its  advantage  to  describe  the  interface evolution.  PFM  is  coupled  with  the  crystal  plasticity  finite  element  method  (CPFEM),  which  makes  it possible to investigate the interaction between the helium bubbles and the collective behaviors of dislocation assembles.  It  is  found  that  the  heterogeneity  of helium  bubbles  induces  a  local  concentration  of plastic deformation, which leads to a rarefaction wave along the propagation direction of the shock wave. From an energy  perspective,  it  is  inferred  that  both  the  growth  of helium  bubbles  and  the  plastic  deformation  are driven by the strain energy, which indicates that these two processes may compete with each other. 

Keywords: shock loading；helium bubble；phase field method；crystal plasticity
